# `render`

- Draws 3D and screen-space UI `DrawList` data with wgpu. Pipeline and materials: `docs/rendering/pipeline.md`. Other drawing topics are listed in `docs/rendering.md`; open one.
- `renderer.rs` is `Renderer` and `TextureRenderer`; `renderer/types.rs` has the GPU types and `renderer/scene.rs` draws a frame. `lighting.rs` plans uniforms, tiles, shadows and batches. `post.rs` blooms, tone-maps and runs FXAA, and below 100% render scale upscales and sharpens (`upscale.wgsl`, FSR 1's EASU and RCAS, MIT, notice in `NOTICE`); `tone_mapping.rs` is the CPU copy of `post.wgsl`'s curves (keep them matching); `grading.rs` is the composite pass's second bind group for `DrawList::grading` (`GradingUniform` matches `Grading` in post.wgsl; the lookup table's 3D texture exists only while used; `docs/rendering/post.md`). `lens.rs` is `DrawList::lens`: depth of field's pass (`depth_of_field.wgsl`, into `FrameTargets::depth_of_field`, which bloom and the composite read in the scene's place, alive only while drawn, keeping the prepass alive) and `add_lens`, which fills `PostUniform`'s lens values for the composite pass's vignette, grain, chromatic aberration and sharpening. `temporal.rs` is motion vectors, TAA and motion blur (`temporal.wgsl`, `vs_motion`/`fs_motion` in shader.wgsl; `FrameTargets::temporal` and `History`, which keeps last frame's camera, items by `DrawItem::id` and joints; `TemporalUniform` starts with shader.wgsl's `MotionView` and matches `Temporal`, `MotionInstance` matches `MotionIn`; `docs/rendering/temporal.md`). `ui_pass.rs` builds quads. `adapters.rs` picks the card and API (DirectX 12 on Windows; route new devices through `adapters::adapter`). `video_memory.rs` reads the card's memory from the system (wgpu doesn't say): `Capabilities::video_memory`, which the memory budgets are worked out from (`docs/rendering/settings.md`); a renderer without an adapter asks `adapters::opened_card_memory`, so open every device through `adapters::with_ray_queries`. `gpu.rs` uploads resources and `uploads.rs` does so on a thread while streaming (`set_background_uploads`); `texture_budget.rs` shrinks the least recently drawn textures to fit the settings' texture memory budget (GPU copies of their smaller mips). `undrawn.rs` frees what stops being drawn: after ten seconds, or, in a renderer told to keep it (`set_keep_undrawn`: the player's window, the editor's viewport; ADR-0051), meshes and color textures only past `mesh_budget` and `texture_budget`, the least recently drawn first (`docs/rendering/models.md`). `debug_views.rs` is the editor's debug views (`DebugView`, `debug_views.wgsl`), built only with the `debug-views` feature, which only the editor turns on. `gpu_timer.rs` times each `FramePass` on the GPU for `RenderStats`, and the prepass and the scene pass by what is drawn (`DrawnPart`: stamps between draws where the part changes, which solid items are sorted by within a distance band, `SortKey::part`; `docs/rendering/performance.md`). `depth_start.rs` starts the scene pass's depth a step behind the prepass's (one sample a pixel only), and solid batches that leave no pixel out are lit with no `discard` (`PrefillPipelines::whole`), so depth is tested before lighting: both must keep the picture pixel for pixel, as must any change to the order solid batches are drawn in (`docs/rendering/performance.md`); `probe.rs` and `occlusion_probe.rs` (what hidden items cost, `AXCENITY_OCCLUSION_PROBE`) are measuring switches. `cpu_timer.rs` times `ScenePipeline::draw` on its thread section by section (`CpuSection`, `RenderStats::cpu_times`: put a new per-frame pass in a section) and `latency.rs` a frame's start to its finished picture, for benchmarks. `clusters.rs` keeps what never changes about each group of items (`DrawList::chunks`): `Draw::cluster` and `Draw::at` say which group and item a draw is, and a pass that needs something fixed of a grouped item reads its `Cluster`, not the item (add it there, and to `tests/grouped_items.rs`, which checks a grouped list draws exactly as its items listed singly). `pacing.rs` is `FramePacer`, which says whether a host's next frame waits for the display or starts while the GPU draws the last (ADR-0052); a renderer whose frames are shown is one frame ahead (`set_one_frame_ahead`: `ScenePipeline::wait_for_frame_before`, the wait in `RenderStats::gpu_wait`), never an offline one. `GraphicsSettings` (presets, overrides, `automatic`), `Capabilities`, `effective` and `Camera` are plain data in `render-types` (re-exported; `docs/rendering/settings.md`), and `graphics.rs` keeps the GPU side (`read_capabilities`); `TextureRenderer::limit_capabilities` forces fallbacks for tests. `occlusion.rs` draws the depth and normal prepass and ambient occlusion (`ssao.wgsl`) into `FrameTargets`, which owns every frame target. `environment.rs` bakes the sky into environment maps (`environment.wgsl`) only when it changes, and works out its spherical harmonics on the CPU (`docs/rendering/sky.md`); `probes.rs` filters reflection probes' bakes into a cubemap array (`ProbeRaw` matches `Probe` in lighting.wgsl) and `probe_bake.rs` bakes one (`TextureRenderer::bake_reflection_probe`) or a grid of light probes (`bake_light_probes`); `light_probes.rs` keeps light probe volumes' probes in one storage buffer (`VolumeRaw` matches `Volume` in lighting.wgsl), and `realtime_gi.rs` traces a few of them again each frame with a kept `ProbeCamera`, summing them on the GPU (`light_probe_sum.wgsl`, a copy of `cube_light`: keep them matching); `fog.rs` packs `DrawList::fog` (`FogRaw` matches `Fog` in fog.wgsl, which every scene shader and sprite.wgsl include) and runs volumetric fog's froxel grid (`volumetric_fog.wgsl`, compute, seeing the frame's bindings through a compute-visible copy of `frame_layout_entries`; `docs/rendering/fog.md`); `clouds.rs` packs `DrawList::clouds` (`CloudsRaw` matches `Clouds` in clouds.wgsl, which every shader including lighting.wgsl includes, with cloud_fill.wgsl after it) and keeps the wind's drift between frames, and `cloud_trace.rs` traces the sky's clouds before the scene pass (`cloud_trace.wgsl`, which has its own `cloud_fill` reading the shapes' texture: half size, then each pixel, into the texture `fs_sky` reads at its bind group 2; `FILL_SIZE` and `FILL_SPAN` match `CLOUD_FILL_TEXELS` and `CLOUD_FILL_SPAN`; `docs/rendering/clouds.md`); `DrawList::weather` is `Frame::weather`, which `light_surface` applies first (`weathered`, `docs/rendering/weather.md`), and `DrawList::weather_boxes` (WeatherVolumes) is `Frame::weather_boxes` (`WeatherBoxRaw` in `types.rs` matches `WeatherBox` in lighting.wgsl; their count is `Frame::precipitation.z`), followed by `Frame::weather_prints`, the last field of the frame's uniform: the snow's print map (`WeatherField::prints`, `WeatherPrintCells`), which `upload_weather_prints` writes after the field's cells in frame binding 19, only the rows that changed (`weather_print` reads it; `PRINT_LEVELS` matches `WEATHER_PRINT_LEVELS`); `water.rs` is `Water` and the wave grid (`water_surface`); `renderer/water.rs` draws water first among see-through items and, from Medium reflection quality, splits the scene pass to copy the solid scene (`water_copy.wgsl`) into `SceneCopy`, bound in frame binding 7's place (`water_frame_bind_group`), for `water.wgsl` (`docs/rendering/water.md`); `DrawList::wind` is `Frame::clock.yzw` and `DrawItem::sway` is `InstanceRaw::sway`, which `swayed` in shader.wgsl applies in `vs_main` and `vs_shadow` alike (`docs/rendering/wind.md`), by each corner's weights for a mesh with `MeshSource::foliage` (`foliage.rs`: the frame's binding 20, `InstanceRaw::skin = [first, FOLIAGE]`, which every reader of `skin` must treat as at rest; ADR-0053); `Material::shading` is `MapsUniform::shading` and `toon`, and `fs_main` picks `light_surface`, unlit, `toon_surface` (a toon ramp is bound in the specular map's place; `docs/rendering/stylized.md`), `hair_surface` (`hair.wgsl`: atlas data in the metalness map's place, flow in the specular map's, colour values in the surface parameters' place, hashed cut-outs; `docs/rendering/hair.md`), `cloth_surface` (`cloth.wgsl`: sheen colour in the toon row, its albedo table checked by a test; `docs/rendering/cloth.md`) or `skin_surface` (`skin.wgsl`; hair.wgsl and cloth.wgsl follow it everywhere it is included; skin's defined normal map is bound in the specular map's place, its makeup and marking masks (`SkinLayers`, ADR-0042) in the metalness, emissive and opacity places with their values in the surface parameters' place; its pre-integrated table is checked by a test; `docs/rendering/skin.md`); `Material::outline` is `MapsUniform::outline` and `Batch::outline`, drawn after the solid items by `outline_pipeline` (`vs_outline`/`fs_outline`, the standard shader whatever the surface shader), and `DrawList::edges` keeps the prepass alive (`targets_used`) for `edges.wgsl`, drawn after the sky through `OcclusionTargets::edge_group`; the sky pass is drawn after solid items, kept by its depth test to uncovered pixels. `atmosphere.rs` is the CPU model of air scattering (`Atmosphere`, its transmittance table `Air`), and `renderer/atmosphere_sky.rs` turns a `Sky` into what's drawn (`SkyLook`: colors dimmed by daylight, or an atmosphere's sky image, worked out only when it changes). `sky.wgsl` is shared by the scene and bake shaders, and its gradient has a CPU copy there. `surface_shaders.rs` checks a material's WGSL `surface` function with naga, reports its errors on its own lines, and caches its pipelines by the code's hash (`SurfaceShader`; the code goes after `gpu::SCENE_TEMPLATE`, in surface.wgsl's place: shader.wgsl's `SurfaceInput` and `Surface` are its API, `docs/rendering/models.md`). `lod.rs` picks each item's level of detail with hysteresis and cross-fades (`LodStates::resolve`, before upload) and applies `DrawItem::cull_distance`; from `STAND_IN_LEVEL` a mesh's `MeshSource::stand_in` (a model's `_PROXY`) takes its place in the farthest cascade (`FarCascadeLods`) and the ray traced scene, and pieces it covers are left out (`StandInKey::mesh`). It also says how much of its shadow a painted plant casts (`ShadowReach`, `Draw::shadow`: whole, then thinning out before its reach ends): the shadow maps dither it (a caster's `InstanceRaw::emissive_fade.w`, `fs_shadow_cut_out`) and ray traced shadows let rays through (`CutOutRaw::casting`, `casts_on_this_ray`), and a change to one needs the other (`docs/rendering/shadows.md`). `culling.rs` tests bounding spheres against each view's `Frustum` (`plan_draws` culls the camera's, `casters_in_views` each shadow view's, grouping them by mesh and material); a caller's mesh is bounded by its corners (`GpuMesh::bounds`), never assume the unit cube for one. `lamp_shadows.rs` keeps lamps' shadow layers between frames by a fingerprint of everything the shadow shaders read (moving casters drawn over a kept copy): a value those shaders start reading must go into `fingerprint`, or into `moves` if it changes every frame (`docs/rendering/lights.md`). `grid.rs` draws the editor's measuring grid (`DrawList::grid`, `grid.wgsl`; `GridUniform` matches `Grid` there). `decals.rs` draws `DrawList::decals` (projected decals, `decal.wgsl`) from the prepass after the sky, limited by `EffectiveGraphics::decals`; `DrawItem::decal_role` is `InstanceRaw::sway.w` (`ROLE_CHARACTER` marks the prepass normal's alpha, `ROLE_DECAL` nudges a face decal's depth; `docs/rendering/decals.md`). `sprites.rs` draws particles; `gpu_particles.rs` moves, bitonic-sorts and writes `DrawList::particle_emitters` as `SpriteRaw`s on the GPU (`particles.wgsl`, keep its motion and look matching `scene/src/particles.rs`; `docs/rendering/particles.md`); a colliding emitter keeps the prepass alive and lands on it (`collide`, `SceneDepthUniform` matches `SceneDepth`). `fonts.rs` lists the built-in UI fonts (`BUILT_IN_FONTS`, plus bold and italic `VARIANTS`); a project's fonts come in `DrawList::fonts`. `renderer/ray_tracing.rs` is hardware ray tracing's acceleration structures (`RayScene`: a BLAS per mesh, small still items grouped into BLASes by the square of ground with one TLAS instance a group (`ray_groups.rs`; a group's geometries are its items' own meshes placed by transform), posed items' BLASes from the posed buffer, swaying items bent by `ray_sway.rs` into BLASes they share as geometries, a TLAS of the items within the ray tracing distance, made only while something traces rays and parked, BLASes kept, through frames that trace nothing while a ray traced effect is on (`parked_ray_scene`, `may_trace_rays`); a hit's slot is `instance_custom_data + geometry_index` in every shader that reads one) and the Ray Hits view (`ray_hits.wgsl`); open devices through `adapters::with_ray_queries` (`docs/rendering/ray-tracing.md`); `renderer/screen_reflections.rs` is screen-space reflections (`screen_reflections.wgsl`: marched through the prepass's depth, last frame's `FrameTargets::hdr` read where the ray lands, into the same frame binding 18 buffer as ray traced reflections, which take its place when drawn; `Frame::ray_reflections.w` 1 also turns on `sky_open_along`'s shading of the sky's reflection; `docs/rendering/reflections.md`); `renderer/path_tracer.rs` is the editor's Path Traced view (`path_tracer.wgsl`, sums shown by `path_traced_view.wgsl`, normals copied by `path_tracer_normals.wgsl`; `PathTraceUniform` matches `PathTrace` in both; only the frame bindings in `FRAME_BINDINGS`); `renderer/ray_cut_outs.rs` lets rays through cut-outs' holes (a non-opaque BLAS per cut-out mesh, its texture coordinates copied by `ray_cut_out_uvs.wgsl`, each texture's alpha in an array layer; `CutOutRaw` matches `CutOut` in ray_shadows.wgsl and in `ray_cut_outs.wgsl`, which ray traced AO and GI include). `renderer/text.rs` picks each rich text span's face, fits `TextScaled` text and makes outline, shadow, faux bold and decoration passes (one shaped copy per paint layer).
- Do not add dependencies on `core`, Instances, scripts or winit; world-to-draw conversion belongs in `scene`. Animated meshes are morphed and skinned once a frame by a compute pass (CO8: `posing.rs`, `posing.wgsl`; every pass reads the posed buffer at frame binding 9 through `pose_corner`, and ray tracing builds posed BLASes from it; `InstanceRaw::skin` is `[first posed corner, 1]`), every posed mesh taken into one arena so a frame is two dispatches, from what `skinning.rs` keeps per mesh (`MeshSource::skin_joints`/`skin_weights`, blend shapes shape by shape from `MeshSource::morph`; weights from `Skin::morph_weights`, only non-zero ones walked; `docs/rendering/animation.md`); meshes whose corners change otherwise keep their key and change `MeshSource::version`, and `update_custom_mesh` rewrites them. The shadow pipelines' vertex and instance layouts give each attribute's offset by hand (the cut-out one reads texture coordinates, opacity and cutoff too): keep them matching `Vertex` and `InstanceRaw`.
- Keep `SpriteRaw` and `SpriteUniform` (`renderer/sprites.rs`) aligned with `sprite.wgsl`, and `UiVertex` (`UI_BOX`, `UI_SHADOW`, `UI_INSET_SHADOW`, its `clip` box, `NO_CLIP` for none) with `ui.wgsl`; text is cut to a `UiClip` through glyphon's bounds. Turned UI items (`rotation_degrees`) turn their quads; glyphon can't turn text, so `renderer/turned_text.rs` draws turned text upright onto a sheet (premultiplied, read by `fs_sheet`) and draws that turned with the images. `ui_pass.rs` cuts sliced images (`UiSlice`) into pieces.
- Keep `InstanceRaw`, `FrameUniform` (lighting.wgsl's `Frame`), `MapsUniform`, the vertex layout and material bindings aligned with `shader.wgsl`, and coordinate wgpu API changes with the workspace version. The item shader reads 16 sampled textures (8 frame, 8 material), wgpu's default per-stage limit: a new frame texture must share or replace a binding. Its vertex and instance layouts use all 16 vertex attributes (the default limit): pack a new per-item value into an existing one.
- A frame is recorded through `FrameEncoders` (`renderer/encoders.rs`): its parts are encoded on the renderer's threads together and submitted in order. Start a part (`encoder.part`) only between passes, before a run of many draw calls. Bind the ray traced scene (the TLAS) only in a pass that traces: wgpu walks every instance of it at submit for each pass that binds it (`docs/rendering/ray-tracing.md`). Ask each shadow ray once for solid items and cut-outs together; ambient occlusion asks the solid items first, then the cut-outs only between `near` and that hit (`ray_ao.wgsl` `nearest_hit`, faster in Overgrown Street's dense leaves).
